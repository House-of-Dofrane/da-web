x-height gap vs. A

Fraunces italic 0.444 em against Iowan italic 0.477 em, measured from the files.

The CLS problem, stated plainly. With font-display: swap the hero paints in the fallback first, then re-paints in Fraunces. Because the two faces are 7 % apart in x-height and further apart in ascent, the three headline lines change height and the page jumps. That is a Cumulative Layout Shift hit on the single most-measured element on the site. The fix is not optional — it is a metric-matched fallback face, and these are the measured numbers for ours:

@font-face{                          /* stands in for Fraunces until it loads */
  font-family:"Fraunces fallback";
  src:local("Iowan Old Style Italic"), local("Georgia Italic");
  size-adjust:93.1%;                 /* 0.4440 / 0.4771 x-height */
  ascent-override:97.8%;             /* 1956 / 2000 upm */
  descent-override:25.5%;
  line-gap-override:0%;
}
@font-face{                          /* stands in for Inter until it loads */
  font-family:"Inter fallback";
  src:local("Helvetica Neue"), local("Arial");
  size-adjust:105.3%;                /* 0.5459 / 0.5186 x-height */
  ascent-override:96.9%;
  descent-override:24.1%;
  line-gap-override:0%;
}

Both overrides are live on this page — B is already rendering with them. Ship B without them and the headline shifts on every cold load.

The ruling

What each answer commits us to.

Choose A

  • §5 closes today. Nothing is blocked on a font.
  • 0 KB, 0 requests. The 0.8 s LCP stays as measured.
  • No CLS risk from a swap, ever.
  • Iowan Old Style is Apple-only. Windows and Android fall to Georgia, so the display face is not the same face for everyone who sees it.
  • The brand documents keep naming a typeface we do not use.

Choose B

  • One face for every visitor on every platform. That is the real argument.
  • Fraunces' soft, high-contrast italic is closer to the register the hero is reaching for.
  • 57.1 KB and 3 preloads added to first paint.
  • Requires the two fallback faces above, permanently, or the hero jumps.
  • Requires a +7.5 % pass on every display size to hold the current optical scale.
